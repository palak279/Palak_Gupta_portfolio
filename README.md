# Personal Portfolio Website

A personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, education, and experience.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Intersection Observer API

## ✨ Features

* Responsive and clean design
* Interactive scroll-based reveal animations
* Animated star background
* Clickable stars with sparkle effects
* About Me section
* Skills and technologies
* Projects showcase
* Education and experience
* Personal profile photo
* Contact section

## 📁 Project Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── images/
│   └── photo.jpeg
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional setup is required.
